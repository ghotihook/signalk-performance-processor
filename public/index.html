    Fixed in the plugin, so the numbers stay trustworthy at the edges.

      Damping

      Seconds; 0 is none. Like the H5000's damping: each value follows its input with this time constant, reaching about two thirds of a change after that many seconds. Heading is never damped: it needs the same lag as apparent wind, or a yaw swings TWD, so apparent wind must arrive undamped (turn off wind damping at the instrument). Check on the Live page that TWD stays put through a yaw. TWA (and the ground wind angle) is TWD less the heading, sent with each heading update; its damping only steadies the number you read, and does not touch TWD. 0 sends every yaw as it happens, as an autopilot may want.

      Fallback magnetic variation

      Used only when nothing on the boat sends true heading or magnetic variation. Normally your GPS supplies variation and this is never used; the Live page shows which applies.

      Input sources

      Choose the instrument to read for each input. Auto picks the sensor with the highest data rate: in the first 2 s after the plugin starts it counts each sensor's messages and keeps the one sending most often for as long as it sends. If it goes quiet, the busiest other sensor takes over and the status says so. That is not necessarily the most accurate one (a 10 Hz IMU wins over a 1 Hz compass, whichever reads truer). Auto reads data connections only, never another plugin's output (a copy, later and slower, or already corrected), and never mixes two sensors. Choose a source here to override it: a chosen source is never replaced.

      Apparent wind must be raw: AWA and AWS as the masthead measures them, uncorrected and undamped. Take the wind tables out of the instrument and set its wind damping to 0, or choose a source ahead of it; this plugin corrects and damps them itself. Keep the masthead alignment in the instrument.

      Beta. Every few minutes the plugin reads the latest sailing from the history (signalk-questdb or another provider), classes it and keeps what it found, never the data itself. From raw inputs only (paddlewheel, masthead, compass, heel, GPS), so the tables in use change nothing here. Over days the findings build up a histogram per table cell. Nothing here changes a table: compare, then paste a proposed table into Calibration if you trust it.

      What it has seen

      Windows are 2 minutes, classed on raw TWA: up under 70°, between 70°–80°, reach 80°–120°, down beyond. Compliant: apparent wind, STW, heading and heel all there, sailing over 1 kn. Stable: steady enough to average (heading, TWA, TWD, STW and TWS each within a spread). Only findings that are both are used for the tables.
