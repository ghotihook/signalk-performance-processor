    Built-in limits

    Fixed in the plugin, so the numbers stay trustworthy at the edges.

      Damping

      Seconds; 0 is none. Like the H5000's damping: each value follows its input with this time constant, reaching about two thirds of a change after that many seconds. Heading damping lines heading up with an apparent wind the instrument has already damped, so a yaw cancels instead of swinging TWD.

      Fallback magnetic variation

      Used only when nothing on the boat sends true heading or magnetic variation. Normally your GPS supplies variation and this is never used; the Live page shows which applies.

      Input sources

      Choose the instrument to read for each input. "Any" takes every source except this plugin. For STW the blank choice is "Auto (sensors only)": STW from data connections, never STW another plugin has published. Pick your instruments, not another correcting plugin, so nothing is corrected twice.

      Apparent wind must be raw: AWA and AWS as the masthead measures them, uncorrected and undamped. Take the wind tables out of the instrument and set its wind damping to 0, or choose a source ahead of it; this plugin corrects and damps them itself. Keep the masthead alignment in the instrument.
